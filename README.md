# Flight Booking App

This is basically a flight booking app that I made for no reason. It is built with Next.js, TypeScript, Tailwind CSS, and Prisma. It uses the Gemini API to generate flight suggestions based on user input.

It sometimes might take a while to load the flight suggestions, but it is worth the wait. Solved most of the bugs, if there are any left, and you find them please report them to me.

## Run Locally

Clone the project

```bash
  git clone
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
npm install
```

Add enviroment variables(go to https://generate-secret.vercel.app/32 and generate a random secret for AUTH_SECRET)

```bash
Add GOOGLE_GENERATIVE_AI_API_KEY & AUTH_SECRET & POSTGRES_URL
```

Start the server

```bash
npm run start
```
